# 기록관 일지

기록물관리전문요원의 기록관리·정보공개 실무와 연구 블로그입니다.

- 주소: https://lchh56789.github.io/blog/
- 글은 `index.html`의 `POSTS` 배열에 있습니다. 새 글은 배열 맨 위에 객체를 추가하고, 작성 예정 글은 `status`를 `"planned"`에서 `"published"`로 바꾼 뒤 `body`를 채웁니다.
- 분류 코드: CA 커리어 아카이브, RM 기록관리 실무, OI 정보공개, ST 표준 읽기, UA 대학기록관 노트, RN 연구 노트
- 관리번호 형식: 분류코드-등록연도-일련번호 (예: CA-2026-002)
